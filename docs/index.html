AgentForge is a lightweight Go runtime for model-driven tool execution. It gives AI models a controlled way to use practical business tools—with bounded execution, validated inputs, and permissions that default to deny.

Designed for practical work

Small runtime. Clear boundaries.

A focused foundation for building AI-assisted workflows without starting with a large platform or opaque automation layer.

01

Controlled tool use

Only registered tools are available to the model. Each tool requires an explicit permission grant.

02

Bounded execution

Limits model/tool turns and supports context cancellation and execution timeouts.

03

Validated data

Tool arguments and results are checked against the project's supported JSON Schema subset.

04

Provider boundary

A small provider interface separates orchestration from the current OpenAI Responses API adapter.

05

Local-first tools

Deterministic text and CSV analysis can run directly from the CLI without a model API key.

06

Testable foundation

Go tests cover provider behavior, tool execution, validation, and permission enforcement.

How it fits together

A deliberately simple architecture.

The model proposes a tool call; the runtime validates and authorizes it before execution.

Application / CLIPrompt · config · permissions
Agent runtimeBounded orchestration loop
Model providerProvider interface · OpenAI adapter
Registered toolsValidate · authorize · execute
Permission checks are application-level controls, not an operating-system sandbox. Tools execute with the privileges of the process running AgentForge.

The example uses fictional records and illustrative values. The win rate is calculated from closed leads only (won + lost). AgentForge reports descriptive metrics; it does not forecast revenue or modify CRM records.
Project status

Built in the open.

AgentForge is an evolving developer project, currently focused on a dependable tool runtime and business-relevant examples.

  • Go runtime and CLI
  • OpenAI Responses API adapter
  • Default-deny tool permissions
  • Automated tests, vet, and CI build
  • Local business-data analysis examples

What it is — and isn't

AgentForge demonstrates controlled model-to-tool orchestration and deterministic local analysis. It is an early-stage foundation, not a production-ready autonomous platform.

  • Live model/API smoke test remains a separate setup step.
  • No persistent task history or workflow scheduler yet.
  • Application permissions do not replace sandboxing or security review.
